# OccultSky

OccultSky is a Python toolkit for searching historical lunar occultation events of planets, powered by Skyfield. 

## Data Sources

### NAIF SPICE Kernels

Downloads de441.bsp from https://ssd.jpl.nasa.gov/ftp/eph/planets/bsp/ for high-precision ephemeris calculations covering 13,200 BCE – 17,191 CE.
